# Original artwork — do not modify

Fourteen photographs of physical paintings and drawings by Alexandr Goriainov:
oil, acrylic, watercolour, graphite, ink, and one painted on glass.

**These files are the masters. Nothing writes to this directory.**

Every image the site serves is *derived* from here — deskewed, cropped, colour-
normalised, resized and compressed by the pipeline described in
[`../docs/PLAN.md`](../docs/PLAN.md) §Phase 4. If a derivative is ever wrong, it
is regenerated from these files; the originals are never edited in place and
never overwritten.

They are photographs, not scans: shot hand-held, so the canvases lean, the
lighting differs between them, and several include the wall, the table or the
paper margin. That is what the restoration pass exists to fix — **without
repainting a single brushstroke.**
