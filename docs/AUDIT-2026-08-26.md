# What we are missing — audit, 2026-08-26

Requested by Tim mid-build. Ranked by how much each item matters, not by how
recently anyone thought about it.

## 0. THE BIG ONE: nothing has been deployed

Production alexandrgoriainov.com still serves the December CRA build — the
blocky gallery that refuses to open on a phone. Every improvement of this
entire effort exists only on a dev server. Worse: the LIVE site still fires
GA4 with no consent on a child's website in the EU, which was identified as
defect N3 on day one and fixed nowhere that visitors can feel it.

Deploying is one push (the Pages project auto-builds `main`), but it is Tim's
gate: current state replaces the old site wholesale.

## 1. Legal / plan debt from the approved plan, still open
- Cookie consent + Consent Mode v2 (Phase 3): built NOWHERE, live site is raw.
- Locale URL routing + hreflang + prerender (Phase 2b): locale toggle exists,
  URLs do not. `/en/`, `/ru/` still 404-equivalent.
- HUD strings only partly localised: Hub / Map / Controls buttons, map labels,
  compass — English-only.
- OG image / Twitter card / structured data (N4): link previews still blank.
- Alexandr's own words: still my placeholder; waiting on him.
- Avatar: legs are placeholders (no photo), his approval never given.
- Artwork restoration (Phase 4a deskew) and KTX2 pipeline: raw 17MB PNGs are
  STILL served in the legacy scene and fullscreen viewer.

## 2. World quality spread
- 16 of 18 worlds are still voxel with dead atmospheres bar the fog fix.
- Poppy has activities but not its brief's structures (petal shelters, bare
  capsules, speckle pools). Pagoda got its dressing; poppy world's own is
  next.
- Subject worlds have NO real-content activities — the entire point of their
  lore (checkable maths, growing crystals, barter chains) is unbuilt.
- Return door is still the study's criticised slab-and-beacon.
- 16 worlds lack courted skies (plan exists, ~80cr each once pano vehicle is
  settled).

## 3. Feel
- ZERO audio anywhere. For a young audience this is the cheapest huge win:
  a seed chime, a shrine bell, wind in the grass — WebAudio synthesis, no
  assets, no credits.
- Textures: everything is flat vertex colour. No surface grain anywhere.
- Character: the block avatar now reads mismatched inside painterly worlds.
- No celebration moments: gathering the 10th seed feels identical to the 1st.

## 4. Engineering debt
- No tests on the activity/streaming layer (chunk window, markDone, map
  agreement with scene).
- Mobile untested on a real device since the smooth path (46k grass blades).
- Persistence decision open (activities are session-only, deliberately).
- The two legacy scenes (voxel dimensions, old CRA world) carry dead weight.
